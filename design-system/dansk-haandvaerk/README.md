# Dansk Håndværk: farver, font og logo

Til Dansk Håndværk-udgaven af prototypen (`?brand=dansk-haandvaerk`). Aflæst fra dhv.dk 3. november 2026: farverne fra sitets tema, fonten fra stylesheetet og logoerne fra forsiden. Det er ikke en officiel designmanual. Dansk Håndværks egne logofiler til medlemmer ligger bag medlemslogin og er ikke brugt her.

## Filer

- `dhv-logo.png`: det vandrette logo (flueben + "Dansk Håndværk"), 638 x 136, transparent.
- `dhv-garanti-maerke.png`: garantimærket, 737 x 745, transparent.
- `tokens.json`: farver med kontrast og brug, samt fonten.

## Kort fortalt

| Rolle | Farve | Bemærk |
|---|---|---|
| Primær | `#005489` blue-01 | Knapper, links, aktive faner. Hvid tekst ovenpå (8:1). |
| Sekundær | `#5484A5` blue-02 | Flader, ikoner, store tal. Ikke lille tekst (4:1). |
| Dekoration | `#A6BED0` blue-03 | Streger og grafik. Aldrig tekst. |
| Lyse flader | `#E8ECF3`, `#D2DEE9`, `#F4F6F9` | Sektioner, kort, sidegrund. |
| Tekst | `#1D1D1B` | Samme sort som i logoet. |
| Mørk flade | `#013B60` | Sidefod, mørke bokse. |
| Accent | `#F00069` | Sparsomt: små pile, enkelte knapper. |

Font: Lexend til både overskrifter og brødtekst (Google Fonts).

De tre blå i fluebenet er den tydeligste genkendelse. Brug dem i den rækkefølge (mørk, mellem, lys) i grafik og ikke som tre ligeværdige knapfarver.

## Regler for brugen

1. Logoerne tilhører Dansk Håndværk. De bruges kun i den udgave, der vises til Dansk Håndværk som forslag, og ikke i Aftalt-udgaven, på salgssiden eller andre steder.
2. Logoet bruges som det er: ingen omtegning, ingen nye farver, ikke strakt.
3. Garantimærket må kun vises der, hvor det handler om garantiordningen, for eksempel i sagsmappen eller kundens kvittering. Det må ikke se ud, som om Aftalt selv giver garantien.
4. Holm ApS er fortsat aftalepart og afsender på arbejdet. Dansk Håndværk er afsender på systemet.
5. Repoet er offentligt. Flyttes projektet til et privat repo, gælder reglerne stadig.
