# Lexend

Lexend Variable, Latin, normal, vægt 100–900. Hentet fra npm-pakken
`@fontsource-variable/lexend@5.3.0` med npm-integritetskontrol.
Kilde: https://www.npmjs.com/package/@fontsource-variable/lexend
Licens: SIL Open Font License 1.1, se `OFL.txt`.

Fonten er også indlejret i `prototype/index.html`, så medlemsudgaven ikke
behøver Google Fonts. Latin indeholder danske æ, ø og å. Aftalt bruger fortsat
sine eksisterende fonte.
